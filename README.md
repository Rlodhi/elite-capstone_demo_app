# EliteA Capstone Demo Application

## Overview

EliteA Capstone Demo Application is a lightweight REST API built with Python and FastAPI. It provides basic application and health endpoints and is used as the sample repository for the EliteA Automated Documentation Sync capstone project.

## Technology Stack

- Python 3.11
- FastAPI
- Uvicorn
- Pydantic

## Entry Points

- Application entry point: `app.py`
- FastAPI application object: `app`

## API Endpoints

- `GET /`
- `GET /health`
- `GET /api/application`

## Configuration

The application supports environment-based configuration.

## Dependencies

Application dependencies are defined in `requirements.txt`.
